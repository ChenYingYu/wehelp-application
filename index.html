WeHelp 第七屆網站開發申請 — 陳映宇

個人簡介和申請動機。

個人簡介：我叫陳映宇，多年前在新北汐止某公司擔任 iOS 軟體工程師，在新冠疫情期間，因家庭因素辭去工作，暫停了軟體開發的職涯。近期隨著情況逐漸穩定，興起重回職場的想法。

申請動機：過去公司的業務為藍牙裝置的開發與 app 應用，在擔任 iOS 工程師的期間，我發覺自己更偏好於處理裝置間的溝通協定與效率，在考量市場就業方向後，我認為後端開發領域是我接下來可以努力的目標。 由於過去沒有接觸過網站開發的工作內容，我認為若以就職為目標，參加WeHelp能夠幫助我在短期內確認該著重的項目，同時兼顧學習的深度與廣度。最重要的是有一群相同目標的夥伴可以一起前進，這是我選擇申請的理由。

曾經做過哪些軟體工程技術相關的學習？若有作品請分享給我們。

除了過去 iOS 相關的工作專案 Melomania 以及 Fostex TM Sound Support， 近期為了體驗AI開發工具，也嘗試 Vibe Coding 了一個網站，讓使用者可以對吃到飽餐廳的所有菜色各別評分：https://master.d3d98ltxc0fmn8.amplifyapp.com/

如果參與這個訓練，會怎麼安排學習時間？

全職投入訓練。為了轉職成為工程師，我在過去便有過每週長時數學習的經驗，這次因具有軟體開發的背景，我期許自己在第一階段快速上手網站開發語言的基礎，除了指定任務之外，也吸收近期軟體開發的新知，儘速找回過去進行開發工作的感覺。

軟體技術日新月異，如何確定投入的領域是正確有回報的？

就我朋友的經驗，同領域內轉換職能，甚至完全轉換領域都很常見。我認為熱門的領域和關鍵字隨年甚至隨季更迭，在養成軟體開發就得終身學習的心態之後，只要定期審視自己當前的技能，並用開放的態度面對新知即可。

請描述一件產生明顯負面情緒的經歷，如何處理該情緒？

大約是幾年前的事情，一位同年齡的朋友在職涯和家庭上都有相當正面的進展，但同時期我在各方面都處於停滯狀態，因此產生了明顯的負面情緒。 後來花了一段時間與親戚溝通，釐清自己的狀況與對未來的想像，這讓我找回自己習慣的節奏，對於他人的進展不再直接比較，能夠以正向的心態去面對。

關於這份申請網頁，分享一個開發時的技術心得。

最近在瀏覽網站時，有個「使章節標題暫留於頂端，在該段落滾動至底時再一起上移」的功能，在視覺上特別吸引我。我認為這個功能可以讓使用者在閱讀內文時隨時回顧章節的主旨，決定實作看看。雖然對網站開發不了解，但我知道前端會使用到 HTML, CSS, Javascript，便以其作為關鍵字，搭配需求去搜尋，順利找到了 CSS 中的 sticky 方法。

如何看待人工智慧的發展對軟體工程師的影響？

我想分成對於現況以及未來兩點：

對於現況，以個人成長的角度，我在沒有網站開發經驗的前提下，透過 Claude 網頁對話生成了前端，再透過 GitHub Copilot 補強功能並部署到 AWS ，還透過 Grok 生成了宣傳卡片，這的確是我未曾想像過的。但我更深刻體會到自己缺乏的領域知識，大幅侷限了開發的可能性。對我來說，當前人工智慧能夠同時讓軟體工程師深刻意識到個人開發的潛能與不足之處。

而對於未來，我認為在軟體開發的流程中，始終會有人擔任與電腦互動的角色。的確隨著科技進步，互動的效率大幅升高。或許工作內容中實作的比重降低，發想、監督和驗證的比例提高。但我想本質不會改變，也就是專注於透過軟體來解決問題，只要有這樣的需求存在，軟體工程就會存在。即使那個職位未來不再叫做軟體工程師，那也無仿。

其他想要對我們說的事情？

感謝課程說明會的直播分享以及老師與助教的即時問題回覆，讓我更了解計畫的內容。WeHelp平台也有很大的幫助，前幾天透過社群夥伴的個人頁面，輾轉連接到某間公司的技術分享GitHub 頁面，內容是AI導入開發流程的實務經驗，我也預計找時間深入了解。
